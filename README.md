An entry for the make.fun bounty **"One Word From Grandma"** — the single
word a grandma would text about AI.

## The word

> witchcraft

She has watched the machine answer questions nobody asked it, write
letters in seconds, and know things no person told it. She does not know
how it works, and she does not need to: there is only one word for a box
that thinks, and it is the one her own grandmother would have used.

## Why this word

- It is the word a grandma would actually text: warm, a little baffled,
  typed to a grandchild, not a slogan.
- The joke lands in one word with no caption: a medieval verdict on a
  futuristic machine.
- It is tied to the machine itself — her explanation of what the thing
  is — not a word that would fit any subject.
- It stands clear of the crowded field: no robot misspelling, no
  doohickey, no contraption.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

The program writes the word to `entry.txt` inside the directory named by
`MAKEFUN_OUTPUT_DIR` (default `/output` when unset). It uses only the
Python 3 standard library, writes no trailing newline, and is
deterministic: every run produces the same bytes.

## The gate

The bounty requires `entry.txt` to be UTF-8 text of 1 to 30 characters,
not only whitespace. This entry is 10 characters, one word.
